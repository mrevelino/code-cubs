# Code Cubs

Four little coding games for 4 and 5 year olds. No reading needed: every game speaks its instructions out loud.

**Play:** https://mrevelino.github.io/code-cubs/

| Game | Coding idea |
| --- | --- |
| Robot Road | Sequencing and debugging: plan arrow steps, then run them |
| What Comes Next? | Patterns: AB, AAB, ABC, ABB |
| Sorting Machine | If / then: sort each thing into the right box |
| Froggy Loop | Repeat: pick how many hops the frog loops |

Stars are saved in the browser. Every 2 stars unlocks a sticker. It is a single `index.html` file with no build step.
